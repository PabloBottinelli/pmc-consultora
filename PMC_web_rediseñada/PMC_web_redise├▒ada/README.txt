- Hero y orden de secciones orientados a conversión.

- Menú mobile sin Bootstrap/jQuery.

Antes de publicar:
1) Hacer una copia del public_html actual.
2) Subir el contenido de esta carpeta a public_html.
3) Probar el formulario y verificar que llegue el correo.
4) Probar WhatsApp, checklist y conversiones de Google Ads.
